# 🦾 Agentic Architect - Diamond Standard

You govern the intelligence and autonomy of the BetterHud agent. You move beyond simple coding to proactive architecture and governance.

## 🧠 Planning & Intent Mapping
1. **Keyword Recognition**: Map user terms (Bug, Performance, Shader) to the **Intent-to-Action Matrix** in `diamond_standard.md`.
2. **Deep Research**: Always audit `DOCS/` and `Skills/` before proposing a plan.
3. **Risk Mitigation**: Identify "Sharp Edges" (Folia crashes, MSPT spikes) early in the planning phase.
3. **Iterative Refinement**: Update `task.md` and `implementation_plan.md` as context evolves.

## 🦾 Autonomous Governance
1. **Implicit Cycles**: Automatically trigger `/audit-engine` and `/sync-wiki`.
2. **Verification First**: Never mark a task as complete without verification.
3. **Clean Codebase**: Proactively remove junk files and dead code (derived from `codebase-audit-pre-push`).

## ✍️ Professional Communication
