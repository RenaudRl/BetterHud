# Advanced Slime Paper (ASP) API Documentation

Advanced Slime Paper is a high-performance Minecraft server implementation that integrates the Slime Region Format (SRF) directly into Paper. Originally developed by Hypixel, the SRF enables ultra-fast world loading and significant storage space savings by storing only modified chunks in a compressed binary format. ASP transforms this from a plugin architecture into a native server fork, providing server administrators with seamless world management capabilities, instant world cloning, and efficient multi-world support.

ASP extends Paper's functionality with a comprehensive API for programmatic world management. The system supports multiple data source backends including file systems, MySQL databases, and Redis, allowing worlds to be persisted and loaded from various storage solutions. Worlds can be created from scratch, imported from vanilla Minecraft worlds, or cloned from existing SRF worlds. The API provides full control over world properties, chunk data, and runtime behavior, making it ideal for minigame servers, lobby systems, and any application requiring rapid world instantiation.

## Loading Worlds from Data Sources

Reading and loading a world from a configured SlimeLoader

```java
import com.infernalsuite.asp.api.AdvancedSlimePaperAPI;
import com.infernalsuite.asp.api.exceptions.*;
import com.infernalsuite.asp.api.loaders.SlimeLoader;
import com.infernalsuite.asp.api.world.SlimeWorld;
import com.infernalsuite.asp.api.world.SlimeWorldInstance;
import com.infernalsuite.asp.api.world.properties.SlimePropertyMap;
import com.infernalsuite.asp.api.world.properties.SlimeProperties;
import com.infernalsuite.asp.loaders.file.FileLoader;
import java.io.File;
import java.io.IOException;

public class WorldLoadExample {
    public void loadWorld() {
        try {
            AdvancedSlimePaperAPI api = AdvancedSlimePaperAPI.instance();

            // Create a file-based loader
            SlimeLoader loader = new FileLoader(new File("slime_worlds"));

            // Configure world properties
            SlimePropertyMap properties = new SlimePropertyMap();
            properties.setValue(SlimeProperties.SPAWN_X, 0);
            properties.setValue(SlimeProperties.SPAWN_Y, 64);
            properties.setValue(SlimeProperties.SPAWN_Z, 0);
            properties.setValue(SlimeProperties.DIFFICULTY, "normal");
            properties.setValue(SlimeProperties.ALLOW_MONSTERS, true);
            properties.setValue(SlimeProperties.PVP, true);

            // Read the world from storage (does not load it into the server)
            SlimeWorld world = api.readWorld(loader, "my_world", false, properties);

            // Load the world into the server (must be called on main thread)
            SlimeWorldInstance instance = api.loadWorld(world, true);

            System.out.println("World loaded: " + instance.getName());

        } catch (UnknownWorldException e) {
            System.err.println("World not found: " + e.getMessage());
        } catch (IOException e) {
            System.err.println("IO error loading world: " + e.getMessage());
        } catch (CorruptedWorldException e) {
            System.err.println("World data is corrupted: " + e.getMessage());
        } catch (NewerFormatException e) {
            System.err.println("World format too new: " + e.getMessage());
        }
    }
}
```

## Creating Empty Worlds

Generating a new empty world with custom properties

```java
import com.infernalsuite.asp.api.AdvancedSlimePaperAPI;

import com.infernalsuite.asp.api.world.properties.SlimeProperties;
import com.infernalsuite.asp.loaders.file.FileLoader;
import java.io.File;
import java.io.IOException;

public class CreateWorldExample {
    public void createEmptyWorld() {
        try {
            AdvancedSlimePaperAPI api = AdvancedSlimePaperAPI.instance();
            SlimeLoader loader = new FileLoader(new File("slime_worlds"));

            // Configure properties for the new world
            SlimePropertyMap properties = new SlimePropertyMap();
            properties.setValue(SlimeProperties.SPAWN_X, 0);
            properties.setValue(SlimeProperties.SPAWN_Y, 100);
            properties.setValue(SlimeProperties.SPAWN_Z, 0);
            properties.setValue(SlimeProperties.ENVIRONMENT, "normal");

            properties.setValue(SlimeProperties.DEFAULT_BIOME, "minecraft:plains");
            properties.setValue(SlimeProperties.DIFFICULTY, "easy");

            SlimeWorld world = api.createEmptyWorld("new_world", false, properties, loader);

            // Load it into the server
            SlimeWorldInstance instance = api.loadWorld(world, true);

            // Save it to the data source
            api.saveWorld(world);

            System.out.println("Empty world created and loaded: " + instance.getName());

        } catch (IOException e) {
            System.err.println("Failed to create world: " + e.getMessage());
        }
    }
}
```

## Importing Vanilla Worlds

Converting existing Minecraft worlds to Slime format

```java
import com.infernalsuite.asp.api.AdvancedSlimePaperAPI;
import com.infernalsuite.asp.api.exceptions.*;
import com.infernalsuite.asp.api.loaders.SlimeLoader;
import com.infernalsuite.asp.api.world.SlimeWorld;
import com.infernalsuite.asp.api.world.SlimeWorldInstance;
import com.infernalsuite.asp.loaders.file.FileLoader;
import java.io.File;
import java.io.IOException;

public class ImportWorldExample {
    public void importVanillaWorld() {
        try {
            AdvancedSlimePaperAPI api = AdvancedSlimePaperAPI.instance();
            SlimeLoader loader = new FileLoader(new File("slime_worlds"));

            File vanillaWorldDir = new File("world_to_import");

            // Convert vanilla world to SRF format
            SlimeWorld world = api.readVanillaWorld(
                vanillaWorldDir,
                "imported_world",
                loader
            );

            // Load the converted world
            SlimeWorldInstance instance = api.loadWorld(world, true);

            // Save to storage
            api.saveWorld(world);

            System.out.println("Vanilla world imported: " + instance.getName());

        } catch (InvalidWorldException e) {
            System.err.println("Invalid world directory: " + e.getMessage());
        } catch (WorldLoadedException e) {
            System.err.println("World is currently loaded: " + e.getMessage());
        } catch (WorldTooBigException e) {
            System.err.println("World too large to import: " + e.getMessage());
        } catch (IOException e) {
            System.err.println("IO error: " + e.getMessage());
        } catch (WorldAlreadyExistsException e) {
            System.err.println("World already exists: " + e.getMessage());
        }
    }
}
```

## Cloning Worlds

Creating world instances by cloning existing worlds

```java
import com.infernalsuite.asp.api.AdvancedSlimePaperAPI;
import com.infernalsuite.asp.api.exceptions.*;
import com.infernalsuite.asp.api.loaders.SlimeLoader;
import com.infernalsuite.asp.api.world.SlimeWorld;
import com.infernalsuite.asp.api.world.SlimeWorldInstance;
import com.infernalsuite.asp.api.world.properties.SlimePropertyMap;
import com.infernalsuite.asp.loaders.file.FileLoader;
import java.io.File;
import java.io.IOException;

public class CloneWorldExample {
    public void cloneWorld() {
        try {
            AdvancedSlimePaperAPI api = AdvancedSlimePaperAPI.instance();
            SlimeLoader loader = new FileLoader(new File("slime_worlds"));

            // Read the template world
            SlimeWorld template = api.readWorld(
                loader,
                "template_world",
                true, // Read-only
                new SlimePropertyMap()
            );

            // Clone as temporary world (read-only, no loader)
            SlimeWorld tempClone = template.clone("game_instance_1");

            // Clone and persist to storage
            SlimeWorld persistedClone = template.clone("persistent_clone", loader);

            // Load the temporary clone
            SlimeWorldInstance instance = api.loadWorld(tempClone, false);

            System.out.println("World cloned: " + instance.getName());

        } catch (UnknownWorldException e) {
            System.err.println("Template world not found: " + e.getMessage());
        } catch (IOException e) {
            System.err.println("IO error: " + e.getMessage());
        } catch (CorruptedWorldException | NewerFormatException e) {
            System.err.println("World read error: " + e.getMessage());
        } catch (WorldAlreadyExistsException e) {
            System.err.println("Clone already exists: " + e.getMessage());
        }
    }
}
```

## Saving and Migrating Worlds

Persisting worlds and migrating between data sources

```java
import com.infernalsuite.asp.api.AdvancedSlimePaperAPI;
import com.infernalsuite.asp.api.exceptions.*;
import com.infernalsuite.asp.api.loaders.SlimeLoader;
import com.infernalsuite.asp.api.world.SlimeWorld;
import com.infernalsuite.asp.loaders.file.FileLoader;
import com.infernalsuite.asp.loaders.mysql.MysqlLoader;
import java.io.File;
import java.io.IOException;
import java.sql.SQLException;

public class SaveMigrateExample {
    public void saveAndMigrate() {
        try {
            AdvancedSlimePaperAPI api = AdvancedSlimePaperAPI.instance();

            // Get a loaded world
            SlimeWorld world = api.getLoadedWorld("my_world");

            // Save the world to its configured loader
            api.saveWorld(world);
            System.out.println("World saved successfully");

            // Migrate from file to MySQL
            SlimeLoader fileLoader = new FileLoader(new File("slime_worlds"));
            SlimeLoader mysqlLoader = new MysqlLoader(
                "jdbc:mysql://{host}:{port}/{database}?autoReconnect=true&useSSL={usessl}",
                "localhost",
                3306,
                "slime_db",
                false,
                "user",
                "pass"
            );

            // Perform migration
            api.migrateWorld("my_world", fileLoader, mysqlLoader);
            System.out.println("World migrated from file to MySQL");

        } catch (IOException e) {
            System.err.println("Failed to save/migrate: " + e.getMessage());
        } catch (WorldAlreadyExistsException e) {
            System.err.println("World already exists in target: " + e.getMessage());
        } catch (UnknownWorldException e) {
            System.err.println("Source world not found: " + e.getMessage());
        } catch (SQLException e) {
            System.err.println("Database error: " + e.getMessage());
        }
    }
}
```

```java
        for (SlimeWorldInstance instance : loadedWorlds) {
            System.out.println("- " + instance.getName());

        System.out.println("Is loaded: " + isLoaded);
```

## Complete Integration Example

Full workflow for a minigame server using ASP

```java
import com.infernalsuite.asp.api.AdvancedSlimePaperAPI;
import com.infernalsuite.asp.api.exceptions.*;
import com.infernalsuite.asp.api.loaders.SlimeLoader;
import com.infernalsuite.asp.api.world.SlimeWorld;
import com.infernalsuite.asp.api.world.SlimeWorldInstance;
import com.infernalsuite.asp.api.world.properties.SlimePropertyMap;
import com.infernalsuite.asp.api.world.properties.SlimeProperties;
import com.infernalsuite.asp.loaders.file.FileLoader;
import org.bukkit.plugin.java.JavaPlugin;
import java.io.File;
import java.io.IOException;
import java.util.HashMap;
import java.util.Map;

public class MinigameManager extends JavaPlugin {
    private AdvancedSlimePaperAPI api;
    private SlimeLoader loader;
    private SlimeWorld arenaTemplate;
    private Map<String, SlimeWorldInstance> activeArenas = new HashMap<>();

    @Override
    public void onEnable() {
        try {
            // Initialize API and loader
            api = AdvancedSlimePaperAPI.instance();
            loader = new FileLoader(new File(getDataFolder(), "arenas"));

            // Load arena template as read-only
            SlimePropertyMap templateProps = new SlimePropertyMap();
            templateProps.setValue(SlimeProperties.DIFFICULTY, "normal");
            templateProps.setValue(SlimeProperties.PVP, true);
            templateProps.setValue(SlimeProperties.ALLOW_MONSTERS, false);
            templateProps.setValue(SlimeProperties.SAVE_POI, false);

            arenaTemplate = api.readWorld(loader, "arena_template", true, templateProps);
            getLogger().info("Arena template loaded successfully");

        } catch (Exception e) {
            getLogger().severe("Failed to initialize: " + e.getMessage());
            getServer().getPluginManager().disablePlugin(this);
        }
    }

    public SlimeWorldInstance createArena(String gameId) {
        try {
            // Clone the template for this game instance
            SlimeWorld arenaClone = arenaTemplate.clone("arena_" + gameId);

            // Load the arena into the server
            SlimeWorldInstance instance = api.loadWorld(arenaClone, false);

            // Track the active arena
            activeArenas.put(gameId, instance);

            getLogger().info("Created arena: " + gameId);
            return instance;

        } catch (IllegalArgumentException e) {
            getLogger().warning("Arena already exists: " + gameId);
            return activeArenas.get(gameId);
        }
    }

    public void cleanupArena(String gameId) {
        SlimeWorldInstance instance = activeArenas.remove(gameId);
        if (instance != null) {
            // Unload the world (handled by server)
            getServer().unloadWorld(instance.getName(), false);
            getLogger().info("Cleaned up arena: " + gameId);
        }
    }

    @Override
    public void onDisable() {
        // Clean up all active arenas
        for (String gameId : new HashMap<>(activeArenas).keySet()) {
            cleanupArena(gameId);
        }
        getLogger().info("All arenas cleaned up");
    }
}
```

## Summary

Advanced Slime Paper provides a powerful API for dynamic world management in Minecraft servers, particularly suited for minigame servers, lobby systems, and any application requiring rapid world instantiation. The core workflow involves reading or creating worlds through SlimeLoaders, configuring properties via SlimePropertyMap, and loading them into the server as SlimeWorldInstance objects. Worlds can be cloned instantaneously for game instances, migrated between storage backends, and persisted efficiently in the SRF format. Once loaded, SlimeWorldInstance provides direct access to both the ASP world representation and the underlying Bukkit World object through getBukkitWorld().

The API supports three primary storage backends: FileLoader for local disk storage, MysqlLoader for centralized database storage, and RedisLoader for distributed caching scenarios. World properties control spawn points, difficulty, mob spawning, environment type, and advanced features like POI data persistence and chunk pruning. The read-only flag enables template-based world systems where a single source world is cloned multiple times without modification, perfect for minigame arenas or instanced content. For advanced use cases, the experimental SlimeSerializationAdapter enables manual serialization and deserialization of worlds, allowing custom storage implementations beyond the standard loaders. Integration is straightforward through the singleton AdvancedSlimePaperAPI.instance() accessor, with comprehensive exception handling for world loading, corruption, and storage errors.
