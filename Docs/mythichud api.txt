## MythicHUD Commands

### Description
Commands are primarily for console access to configure HUD behaviors during gameplay.

Console Command

None

#### Query Parameters
None

This snippet details how to copy MythicHUD resource pack components into the ItemsAdder content folder to ensure proper merging and support for different Minecraft versions. It highlights the need to choose between 'modern' and 'modern-plus' folders and warns against using both simultaneously.

```markdown
- Copy the `MythicHUD/built-pack/modern` folder (*or* the `modern-plus` folder, but NOT BOTH) into the `Itemsadder/Contents` folder.

  - To support versions 1.20.5-1.21.1, copy the `MythicHUD/built-pack/modern` folder into the `Itemsadder/Contents` folder.
  - To support versions 1.21.2+, copy the `MythicHUD/built-pack/modern-plus` folder into the `Itemsadder/Contents` folder.
  - ⚠️You *cannot* use both, see "Overlays Issue" segment below
- MythicHUD's pack elements should now merge on `/iazip` command.
```

### Interact with Player HUD Layouts using HudHolder

Source: https://git.mythiccraft.io/mythiccraft/mythichud/-/wikis/MythicHUD-API/diff_version_id=2e61f18d875b404068c50b836c4f8a8f2b1cc51b&view=parallel&w=1

This Java code demonstrates how to obtain a player's HudHolder and use it to add or remove HUD layouts. It also shows how to check for an active layout.

```java
import io.lumine.mythichud.MythicHUD;
import io.lumine.mythichud.api.hud.HudHolder;
import io.lumine.mythichud.api.layout.ActiveLayout;
import io.lumine.mythichud.api.layout.HudLayout;

import org.bukkit.entity.Player;
import java.util.Optional;

public class HudHolderExample {

    public static void example(Player player, HudLayout hudLayout) {
        HudHolder holder = MythicHUD.getInstance().holders().getPlayer(player);
        if (holder == null) return;

        holder.addLayout(hudLayout);
        holder.removeLayout(hudLayout);

        Optional<ActiveLayout> activeLayout = holder.getActiveLayout("hudlayout"); // "hudlayout" is the ID of the layout
        if (activeLayout.isPresent()) {
            // Layout is active
        }
    }
}
```

### Sending a Pop-Up Message

Source: https://git.mythiccraft.io/mythiccraft/mythichud/-/wikis/Pop-Ups/diff_version_id=1c052a738cb14f8a2c809bc4e81c46f1f0f4bb19&view=parallel&w=1

This endpoint allows you to send various pop-up messages to players. You can specify the player, the type of pop-up, the duration in ticks, and any additional arguments.

```APIDOC
## POST /mythichud popup

### Description
Sends a pop-up message to a specified player. This can be used for various in-game notifications or messages.

### Method
POST

### Endpoint
`/mythichud popup <player> <popup> <ticks> <args separated by '|'>`

### Parameters
#### Path Parameters
- **player** (string) - Required - The username of the player to send the pop-up to.
- **popup** (string) - Required - The type or identifier of the pop-up to display (e.g., 'action-bar').
- **ticks** (integer) - Required - The duration in game ticks for which the pop-up will be displayed.
- **args** (string) - Optional - Additional arguments for the pop-up, separated by '|' characters.

### Request Example
```json
{
  "command": "/mythichud popup Notch action-bar 60 Hello There Notch!"
}
```

### Response
#### Success Response (200)
- **status** (string) - Indicates the success of the command execution.
- **message** (string) - A confirmation message.

#### Response Example
```json
{
  "status": "success",
  "message": "Popup sent to Notch."
}
```

### Example: PvP Death Message
A PvP-focused "Death Message" pop-up that slots in the upper right of the screen:
```
/mythichud popup <victim_name> death_message 100 Player <victim_name> was slain by <killer_name>!
```
```

This snippet demonstrates how to use the 'effect' condition in MythicHUD to check if a player has a specific potion effect. It utilizes the 'e' alias for the effect type and can be used to conditionally apply styles or changes to HUD elements. The effect names are derived from the SpigotAPI.

### Check Player Potion Effect (MythicLua)

Source: https://git.mythiccraft.io/mythiccraft/mythichud/-/wikis/Conditions/Effect_version_id=d43c9b375bd9093e6c6a059b6382d5ed5a6269b3

The 'effect' condition checks if the player has one or more specified potion effects. The 'effect' attribute accepts a single effect name or a comma-separated list of effects. The output of the condition is a boolean indicating whether the player possesses any of the checked effects.

```MythicLua
lucky_charm:
  conditions:
  - effect{e=luck} true color green
  layers:
    icon:
      texture:
        path: assets/luck/clover.png
      offset:
        x: -5
        y: 2
```
