# BTC-CORE API Documentation

BTC-CORE is a highly specialized, high-performance Minecraft server fork built upon Advanced Slime Paper (ASPaper), combining the best features from Paper, Folia, Purpur, Pufferfish, SparklyPaper, Leaf, and Canvas. It provides native SlimeWorld support through the Slime Region Format (SRF), comprehensive performance optimizations, custom event API, security features, and quality-of-life improvements. BTC-CORE targets production environments requiring maximum performance, stability, and enterprise-grade features.

This documentation covers all BTC-CORE specific APIs, configurations, events, and features. BTC-CORE inherits the full Advanced Slime Paper API for world management (see advancedslimepaper api.txt) and extends it with additional capabilities.

## 1. Fork Hierarchy & Compatibility

BTC-CORE inherits from multiple forks in the following hierarchy:

```
Minecraft Server
    └── CraftBukkit
        └── Spigot
            └── Paper
                ├── Folia (Regionized Multithreading)
                ├── Purpur (Gameplay Customization)
                ├── Pufferfish (Performance Optimizations)
                ├── SparklyPaper (SlimeWorld Optimizations)
                ├── Leaf (Async Systems)
                └── Canvas (Parallel Ticking)
                    └── Advanced Slime Paper (ASPaper)
                        └── BTC-CORE
```

### Compatibility Notice

BTC-CORE may break compatibility with plugins expecting standard Paper behavior:

- **Folia Thread Model**: Some operations require region-aware scheduling
- **SlimeWorld Format**: Standard world save/load APIs behave differently  
- **Async Pathfinding**: AI may run on separate threads
- **Optimized Tick Loops**: Some events may fire at different rates
- **Network Layer Changes**: Packet timing may vary due to optimizations

```java
        // Spawn particle...

    public void playSound(Location loc, Player viewer) {
```

## 4. Security Features & Anti-Cheat

### CombatLogManager

Prevents players from logging out during combat.

```java
import com.infernalsuite.asp.security.CombatLogManager;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.entity.EntityDamageByEntityEvent;
import org.bukkit.event.player.PlayerQuitEvent;
import org.bukkit.plugin.java.JavaPlugin;

public class CombatLogExample implements Listener {
    private final CombatLogManager combatManager;
    
    public CombatLogExample(JavaPlugin plugin) {
        this.combatManager = new CombatLogManager(plugin);
    }
    
    // --- Automatic Combat Tagging on Damage ---
    @EventHandler
    public void onDamage(EntityDamageByEntityEvent event) {
        if (event.getEntity() instanceof Player victim) {
            if (event.getDamager() instanceof Player attacker) {
                // Tag both players in combat  
                combatManager.tagPlayer(victim);
                combatManager.tagPlayer(attacker);
                
                victim.sendMessage("§cYou are now in combat!");
                attacker.sendMessage("§cYou are now in combat!");
            }
        }
    }
    
    // --- Handle Combat Log on Disconnect ---
    @EventHandler
    public void onQuit(PlayerQuitEvent event) {
        Player player = event.getPlayer();
        if (combatManager.isInCombat(player)) {
            // Player combat logged - kill them
            player.setHealth(0);
            player.damage(1000);
            
            // Broadcast message
            event.quitMessage(null); // Remove default message
            player.getServer().broadcast(
                net.kyori.adventure.text.Component.text(
                    "§c" + player.getName() + " combat logged!"
                )
            );
            
            // Log the exploit
            combatManager.logCombatLog(player);
        }
    }
    
    // --- Check Combat Status ---
    public boolean isPlayerInCombat(Player player) {
        return combatManager.isInCombat(player);
    }
    
    // --- Get Remaining Combat Time ---
    public long getRemainingCombatTime(Player player) {
        return combatManager.getRemainingTime(player);
    }
    
    // --- Force Remove Combat Tag ---
    public void removeCombatTag(Player player) {
        combatManager.untagPlayer(player);
    }
}
```

### ExploitLogger

Logs and tracks potential exploits and cheats.

```java
import com.infernalsuite.asp.security.ExploitLogger;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.player.PlayerInteractEvent;
import org.bukkit.event.entity.EntityDamageByEntityEvent;
import org.bukkit.plugin.java.JavaPlugin;

public class ExploitDetectionExample implements Listener {
    private final ExploitLogger exploitLogger;
    
    public ExploitDetectionExample(JavaPlugin plugin) {
        this.exploitLogger = new ExploitLogger(plugin);
    }
    
    // --- CPS (Clicks Per Second) Tracking ---
    @EventHandler
    public void onInteract(PlayerInteractEvent event) {
        Player player = event.getPlayer();
        
        // Register the click
        exploitLogger.registerClick(player);
        
        // Check if player exceeds CPS limit
        int currentCPS = exploitLogger.getCurrentCPS(player);
        if (exploitLogger.exceedsCPSLimit(player)) {
            // Log the violation
            exploitLogger.logExploit(player, ExploitLogger.ExploitType.CPS_EXCEED, 
                "CPS: " + currentCPS);
            
            // Cancel the action
            event.setCancelled(true);
            player.sendMessage("§cYou are clicking too fast!");
        }
    }
    
    // --- Reach Validation ---
    @EventHandler
    public void onDamage(EntityDamageByEntityEvent event) {
        if (event.getDamager() instanceof Player attacker) {
            double distance = attacker.getLocation().distance(
                event.getEntity().getLocation()
            );
            
            // Check if reach exceeds configured maximum
            if (exploitLogger.exceedsReachLimit(distance)) {
                // Log the violation
                exploitLogger.logExploit(attacker, ExploitLogger.ExploitType.REACH, 
                    "Distance: " + String.format("%.2f", distance));
                
                // Cancel the attack
                event.setCancelled(true);
            }
        }
    }
    
    // --- Manual Exploit Logging ---
    public void logCustomExploit(Player player, String description) {
        exploitLogger.logExploit(player, ExploitLogger.ExploitType.OTHER, description);
    }
    
    // --- Get Player Violation Count ---
    public int getViolations(Player player, ExploitLogger.ExploitType type) {
        return exploitLogger.getViolationCount(player, type);
    }
    
    // --- Clear Violations ---
    public void clearViolations(Player player) {
        exploitLogger.clearViolations(player);
    }
}
```

### JoinQueueManager

Manages player join queue when server is at capacity.

```java
import com.infernalsuite.asp.qol.JoinQueueManager;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.player.PlayerLoginEvent;
import org.bukkit.plugin.java.JavaPlugin;

public class JoinQueueExample implements Listener {
    private final JoinQueueManager queueManager;
    
    public JoinQueueExample(JavaPlugin plugin) {
        this.queueManager = new JoinQueueManager(plugin);
    }
    
    // --- Handle Player Login ---
    @EventHandler
    public void onLogin(PlayerLoginEvent event) {
        Player player = event.getPlayer();
        
        // Check if server is full
        if (queueManager.isServerFull()) {
            // Check for priority permission
            if (player.hasPermission("btccore.queue.priority")) {
                // Allow priority players
                return;
            }
            
            // Add to queue
            int position = queueManager.addToQueue(player);
            
            // Disallow login, show queue position
            event.disallow(PlayerLoginEvent.Result.KICK_OTHER,
                net.kyori.adventure.text.Component.text(
                    "§eServer is full. You are #" + position + " in queue."
                )
            );
        }
    }
    
    // --- Get Queue Position ---
    public int getQueuePosition(Player player) {
        return queueManager.getPosition(player);
    }
    
    // --- Remove from Queue ---
    public void removeFromQueue(Player player) {
        queueManager.removeFromQueue(player);
    }
    
    // --- Get Queue Size ---
    public int getQueueSize() {
        return queueManager.getQueueSize();
    }
    
    // --- Process Queue (called periodically) ---
    public void processQueue() {
        queueManager.processNextInQueue();
    }
}
```

### MaintenanceModeManager

Controls server maintenance mode.

```java
import com.infernalsuite.asp.qol.MaintenanceModeManager;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.Listener;
import org.bukkit.event.player.PlayerLoginEvent;
import org.bukkit.plugin.java.JavaPlugin;

public class MaintenanceModeExample implements Listener {
    private final MaintenanceModeManager maintenanceManager;
    
    public MaintenanceModeExample(JavaPlugin plugin) {
        this.maintenanceManager = new MaintenanceModeManager(plugin);
    }
    
    // --- Toggle Maintenance Mode ---
    public void enableMaintenance() {
        maintenanceManager.setEnabled(true);
        
        // Kick all players without bypass permission
        for (Player player : maintenanceManager.getPlugin().getServer().getOnlinePlayers()) {
            if (!maintenanceManager.canBypass(player)) {
                player.kick(maintenanceManager.getKickMessage());
            }
        }
    }
    
    public void disableMaintenance() {
        maintenanceManager.setEnabled(false);
    }
    
    // --- Handle Player Login During Maintenance ---
    @EventHandler
    public void onLogin(PlayerLoginEvent event) {
        if (maintenanceManager.isEnabled()) {
            Player player = event.getPlayer();
            
            // Check bypass permission
            if (!maintenanceManager.canBypass(player)) {
                event.disallow(
                    PlayerLoginEvent.Result.KICK_OTHER,
                    maintenanceManager.getKickMessage()
                );
            }
        }
    }
    
    // --- Set Custom Kick Message ---
    public void setKickMessage(String message) {
        maintenanceManager.setKickMessage(message);
    }
    
    // --- Check Status ---
    public boolean isMaintenanceActive() {
        return maintenanceManager.isEnabled();
    }
}
```

### PreDamageCalculationEvent

Fires before damage calculation, allowing modification of damage sources.

```java
import org.bukkit.entity.Entity;
import org.bukkit.entity.Player;
import org.bukkit.event.Cancellable;
import org.bukkit.event.Event;
import org.bukkit.event.HandlerList;

public class PreDamageCalculationEvent extends Event implements Cancellable {
    private static final HandlerList HANDLERS = new HandlerList();
    private boolean cancelled = false;
    
    private final Entity victim;
    private final Entity damager;
    private double baseDamage;
    private double damageMultiplier = 1.0;
    
    // Constructor, getters, setters...
    
    public Entity getVictim() { return victim; }
    public Entity getDamager() { return damager; }
    
    public double getBaseDamage() { return baseDamage; }
    public void setBaseDamage(double damage) { this.baseDamage = damage; }
    
    public double getDamageMultiplier() { return damageMultiplier; }
    public void setDamageMultiplier(double multiplier) { this.damageMultiplier = multiplier; }
    
    public double getFinalDamage() { return baseDamage * damageMultiplier; }
    
    // Event boilerplate...
    @Override
    public boolean isCancelled() { return cancelled; }
    @Override
    public void setCancelled(boolean cancel) { this.cancelled = cancel; }
    
    public static HandlerList getHandlerList() { return HANDLERS; }
    @Override
    public HandlerList getHandlers() { return HANDLERS; }
}
```

Usage:

```java
@EventHandler
public void onPreDamage(PreDamageCalculationEvent event) {
    // Apply RPG damage multipliers
    if (event.getDamager() instanceof Player player) {
        double strength = getPlayerStrength(player);
        event.setDamageMultiplier(1.0 + (strength * 0.01));
    }
    
    // Reduce damage to bosses
    if (isBoss(event.getVictim())) {
        event.setBaseDamage(event.getBaseDamage() * 0.75);
    }
}
```

## 7. SlimeWorld Extensions

### CrossWorldEntityTransfer

Handles pets and mounts following players between worlds.

```java
import com.infernalsuite.asp.entity.CrossWorldEntityTransfer;
import org.bukkit.entity.Player;
import org.bukkit.entity.Tameable;
import org.bukkit.entity.Entity;
import org.bukkit.World;
import org.bukkit.plugin.java.JavaPlugin;
import java.util.List;

public class EntityTransferExample {
    private final CrossWorldEntityTransfer transferManager;
    
    public EntityTransferExample(JavaPlugin plugin) {
        this.transferManager = new CrossWorldEntityTransfer(plugin);
    }
    
    // --- Transfer Player with Pets ---
    public void teleportWithPets(Player player, World targetWorld) {
        // Get player's pets
        List<Tameable> pets = transferManager.getPlayerPets(player);
        
        // Teleport player
        player.teleport(targetWorld.getSpawnLocation());
        
        // Transfer pets
        for (Tameable pet : pets) {
            transferManager.transferEntity((Entity) pet, targetWorld, 
                player.getLocation());
        }
    }
    
    // --- Transfer Mounted Entity ---
    public void teleportWithMount(Player player, World targetWorld) {
        Entity vehicle = player.getVehicle();
        
        if (vehicle != null) {
            // Dismount
            player.leaveVehicle();
            
            // Teleport both
            player.teleport(targetWorld.getSpawnLocation());
            transferManager.transferEntity(vehicle, targetWorld, 
                player.getLocation());
            
            // Remount after transfer
            transferManager.scheduleRemount(player, vehicle);
        } else {
            player.teleport(targetWorld.getSpawnLocation());
        }
    }
    
    // --- Check if Entity Can Transfer ---
    public boolean canTransferEntity(Entity entity) {
        return transferManager.isTransferable(entity);
    }
    
    // --- Register Custom Transferable Entity Type ---
    public void registerTransferableType(Class<? extends Entity> entityType) {
        transferManager.registerTransferable(entityType);
    }
}
```

### Clone Unloaded SlimeWorld API

Clone worlds directly from storage without loading them first.

```java
import com.infernalsuite.asp.api.AdvancedSlimePaperAPI;
import com.infernalsuite.asp.api.loaders.SlimeLoader;
import com.infernalsuite.asp.api.world.SlimeWorld;
import com.infernalsuite.asp.api.world.properties.SlimePropertyMap;
import com.infernalsuite.asp.loaders.file.FileLoader;
import java.io.File;

public class CloneUnloadedExample {
    public void cloneWithoutLoading() throws Exception {
        AdvancedSlimePaperAPI api = AdvancedSlimePaperAPI.instance();
        SlimeLoader loader = new FileLoader(new File("slime_worlds"));
        
        // Clone a world that is NOT currently loaded
        // This is more efficient than loading -> cloning -> unloading
        SlimeWorld clonedWorld = api.cloneUnloadedWorld(
            loader,                      // Source loader
            "template_arena",            // Source world name
            "arena_instance_42",         // New world name
            new SlimePropertyMap()       // Properties
        );
        
        // Now load the cloned world
        api.loadWorld(clonedWorld, false);
        
        System.out.println("Cloned and loaded: arena_instance_42");
    }
}
```

## 8. Async Pathfinding

### PathfindTaskRejectPolicy

Controls behavior when pathfinding queue is full.

```java
import com.infernalsuite.asp.async.path.PathfindTaskRejectPolicy;

public enum PathfindTaskRejectPolicy {
    /**
     * Flush all pending tasks and accept the new one.
     * Best for high-performance servers with many entities.
     */
    FLUSH_ALL,
    
    /**
     * Run the task on the caller thread (blocking).
     * Safer but may cause lag spikes.
     */
    CALLER_RUNS,
    
    /**
     * Discard the new task silently.
     */
    DISCARD,
    
    /**
     * Discard the oldest task in the queue.
     */
    DISCARD_OLDEST;
    
    /**
     * Parse a string to a PathfindTaskRejectPolicy.
     */
    public static PathfindTaskRejectPolicy fromString(String name);
}
```

```yaml
    enabled: true
    max-threads: 4           # Number of pathfinding threads
    keepalive: 60            # Thread keepalive in seconds
    queue-size: 1024         # Max queued pathfind tasks
    reject-policy: "FLUSH_ALL"
```

## Summary

BTC-CORE provides a comprehensive suite of APIs for high-performance Minecraft server development. The core systems include:

1. **Configuration**: Extensive YAML-based settings via BTCCoreConfig for all features
2. **Performance**: PerformanceManager with collision throttling, particle/sound culling, scoreboard batching, light throttling, chunk prefetching, projectile pooling, and redstone throttling
3. **Security**: CombatLogManager for combat logging prevention, ExploitLogger for CPS tracking, reach validation, and exploit logging
4. **QoL**: JoinQueueManager, MaintenanceModeManager, PlayerDataBackupManager for server administration
5. **Events**: Custom events for damage calculation, entity targeting, region transitions, chat formatting, world loading, and chunk population
6. **SlimeWorld**: CrossWorldEntityTransfer for pet/mount handling, cloneUnloadedWorld for efficient world cloning
7. **Async**: Configurable async pathfinding with multiple reject policies
8. **Monitoring**: Sentry integration for error tracking, per-world MSPT commands

All features integrate seamlessly with the Paper/Folia ecosystem while providing enhanced performance and functionality for production environments. Configuration is centralized in btccore.yml with sensible defaults that can be tuned for specific server requirements.

For Advanced Slime Paper world management APIs, see `advancedslimepaper api.txt`.
For Folia threading and scheduling APIs, see `folia api.txt`.
For Paper API documentation, see `paper api 1.21.11.txt`.
